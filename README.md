# LaundryMart - Responsive Hamburger Menu

## Project Description

This project implements a responsive hamburger menu for the LaundryMart website using HTML and CSS.

The hamburger menu is visible only on mobile screens. When the user clicks the hamburger icon, a navigation menu appears on the right side of the screen.

## Technologies Used

* HTML5
* CSS3

## Features

* Responsive navbar
* CSS-only hamburger menu
* Uses the `:focus` pseudo-class
* Right-aligned navigation menu
* Mobile-friendly layout

## Files

* `index.html` - Website structure
* `style.css` - Styling and responsive design
* `README.md` - Project documentation

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Resize the browser to view the mobile hamburger menu.
